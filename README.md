# Домашнее задание к работе номер 4

## Условие Задачи

В зале музея четыре датчика движения (A, B, C, D). Чтобы избежать ложных срабатываний, сигнализация включает запись только если не менее трех датчиков сработали (система интерпретирует срабатывания как "повторяющееся движение", а не "шум"). Запишите условие включения записи.

## 1. Алгоритм и блок-схема

**Алгоритм:**

1. Начало
2. Объявить переменные:
   - A - состояние первого датчика (1 - сработал, 0 - нет).
   - B - состояние второго датчика (1 - сработал, 0 - нет).
   - C - состояние третьего датчика (1 - сработал, 0 - нет).
   - D - состояние четвертого датчика (1 - сработал, 0 - нет).
3. Ввести значения A, B, C, D.
4. Составить условие: сумма срабатываний должна быть больше или равна трем (A + B + C + D >= 3).
5. Вывести результат (1 - запись включена, 0 - выключена).
6. Конец.
